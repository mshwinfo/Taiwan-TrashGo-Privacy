# Taiwan TrashGo — 隱私權政策

「我的垃圾車 Taiwan TrashGo」App 的隱私權政策頁面，以 GitHub Pages 發布，
供 AppGallery 送審時填寫「隱私權政策網址」使用。

- 頁面內容：[`index.html`](index.html)
- 主專案：[mshwinfo/Taiwan-TrashGo](https://github.com/mshwinfo/Taiwan-TrashGo)

## 送審前必做

1. **填入聯絡 Email**：`index.html` 中搜尋 `PLEASE_FILL_EMAIL`（共 2 處，
   連結與顯示文字），改成實際對外聯絡信箱。隱私權政策必須提供聯絡方式。
2. **開啟 GitHub Pages**：本 repo → **Settings** → **Pages** →
   Source 選 **Deploy from a branch**，Branch 選 **`main` / `(root)`** → Save。
   等一兩分鐘後即可取得網址：

   ```
   https://mshwinfo.github.io/Taiwan-TrashGo-Privacy/
   ```

3. 把上面網址填入 AppGallery 送審表單的「隱私權政策」欄位，並同步更新主專案的
   `docs/STORE_LISTING.md` 待辦。

## 維護

政策內容如有變更，請一併更新 `index.html` 上方的「生效日期」。
